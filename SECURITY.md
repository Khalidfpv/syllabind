# Security policy

Syllabind runs locally: it reads your Markdown and images and writes HTML, PDF and Markdown files. The exported
HTML makes no network requests (the `verify_html.py` check enforces this).

## Supported versions
The latest release.

## Reporting a vulnerability
Please do not open a public issue. Use
[Report a vulnerability](https://github.com/Khalidfpv/syllabind/security/advisories/new) instead.
You will get an answer within 7 days.
